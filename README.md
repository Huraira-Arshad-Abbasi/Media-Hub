# 🎬 Media Hub

Media Hub is a responsive web application built with **React** and **Vite** that allows users to search, view, and download high-quality images, videos, and audios from public APIs. It showcases modern frontend development skills, efficient API integration, and an interactive UI design.

🔗 **Live Demo:** [media-hub-chi.vercel.app](https://media-hub-chi.vercel.app)

---

## ✨ Features

* **Multimodal Search:** Discover images, videos, and audio files all in one place.
* **Interactive Overlays:** Hover over any media item to reveal a detailed description of the content.
* **Instant Downloads:** Features a dedicated download button on the top-right corner of every media card for quick access.
* **Global State Management:** Uses **React Context API** to handle search queries and application state seamlessly across components.
* **Fast Performance:** Developed using **Vite** for a lightning-fast development environment and optimized production builds.
* **Fully Responsive:** Designed to provide a smooth user experience across mobile, tablet, and desktop devices.

## 🛠️ Tech Stack

* **Frontend Library:** [React.js](https://reactjs.org/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **State Management:** React Context API
* **Deployment:** [Vercel](https://vercel.com/)
* **APIs:** Integrated with various free, public media APIs.
